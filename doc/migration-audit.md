- 修正 MSVC 环境脚本和 Windows 外壳探针的本机路径处理。

## 尚不能宣称一比一

- 旧版 `artifacts/old-ui.png` 是网页内容截图，新版 `artifacts/new-ui-final.png` 是桌面整窗截图；旧 Tauri 程序自身也有原生菜单。扣除窗口外壳后，顶栏、侧栏密度、表格字距、曲线填充与控件间距仍有可见差异。需要同一窗口尺寸、同一选中报文、同一主题和相同的面板尺寸逐页校准后，才能称为样式一致。
- 旧 Tauri 菜单里的全屏和开发者工具尚无 Flutter 对应入口。其余常用菜单动作（打开、关闭、导出、搜索、主题、紧凑行高、筛选栏）已接入。
- 样本覆盖了提供的 7 份文件及现有合成夹具，没有覆盖 USB PD 3.2 与 UFCS 规范的所有消息、异常帧和边界值。尤其是 EPR/AVS 的全部组合、分块扩展消息以及 UFCS 厂商自定义负载，应补专门向量再核对。
- 本轮外壳探针验证了文件关联共用的路径入口和第二实例转交；真实资源管理器拖放仍需在桌面上手工验证。

## 续核：UI 与操作状态（2026-09-30）

本节为上述未提交迁移改动基础上的续核。上文的测试结果是已有记录，本次没有重跑测试、编译或 Windows 外壳探针，不能视为对本次改动的运行验证。

### 已修正的操作差异

- 侧栏重置筛选保留当前排序，与旧版独立的筛选/排序状态一致；时间窗口复位不再改变排序和“全部/协商/错误”档位。
- 报文类型候选按数量降序、同数量按名称排列；标签徽章显示整份抓包的报文总数，筛选到零条时仍保留总数。
- 搜索框按文档创建状态，切换标签会取消上一份文档尚未触发的防抖输入，避免搜索条件串到另一份抓包。
- 补齐上下方向键按当前筛选/排序视图导航、未选中时从第一条开始、边界停在首尾报文；点击报文和键盘导航会展开详情。
- 详情异步请求只接受最新一次选中的结果，防止连续导航时旧结果覆盖当前详情。
- 补齐标签 Delete/Backspace 关闭入口。
- 纵轴状态归属每份文档和每个曲线档位；切通道重置时间窗口及两档纵轴，切标签保留各自视图。
- 时间轴绘制、点击、悬停和刷选共用绘图区坐标；恢复光标锚定纵轴缩放及旧版的缩放/平移边界；复位按钮始终可用，只复位时间和当前纵轴。
- 曲线区首次明显拖动后锁定为水平刷选或垂直平移；支持 Shift、刻度栏与右键平移，切文档/通道清理临时手势状态。
- 补齐消息头、扩展头、可复制原始十六进制数据，以及 VBUS/IBUS 和对象数/字节数。
- 对照 `USB_PD_Revision_3.2_Version_1.2_2026_05_20.pdf` 第 117 页 Table 6.2 和第 172 页 Table 6.48：修正旧 UI 将扩展头 Data Size 标成 B9–0 的错误，正确为 B8–0、B9 保留；区分 SOP 与线缆报文的头部角色位语义。

### 核对边界

- 旧版筛选后保留视图位置，却不同时刷新详情，可能造成高亮报文与详情不一致；本次保留 NG 清除选中的行为，不复刻这一缺陷。
- 本次优先对齐确定的操作逻辑，不宣称逐像素 UI 一致；上文列出的同尺寸截图校准、原生全屏入口和真实拖放仍待完成。
